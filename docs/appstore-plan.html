0. Блокери — без них далі не йти

0.1. Безкоштовний ключ Gemini не можна використовувати для учнів у ЄС — і це стосується вже нинішнього сайту Умови Gemini API (редакція березня 2026): застосунок, що обслуговує користувачів з ЄЕЗ, Швейцарії чи Великої Британії, має працювати лише через платні сервіси (Cloud-проєкт з білінгом). Безкоштовна квота для них заборонена. Ви з учнями — у Польщі/ЄС, тож сайт уже зараз формально порушує ці умови. App Store лише робить це помітним: Apple перевіряє ліцензійну чистоту сторонніх сервісів (5.2, 5.1.2).
Рішення: увімкнути білінг у Google Cloud (Tier 1) з лімітом бюджету й сповіщенням. Код міняти майже не треба: моделі й ліміти на людину вже є в _shared/config.ts.
0.2. Масштаб: AI розраховано на 10 людей У App Store прийдуть сотні незнайомих людей. Безкоштовних лімітів не вистачить уже на 15–20 активних учнів, а платні виклики без обмежень — це необмежений рахунок. Потрібні денні ліміти на людину (вже є), загальний місячний бюджет із «запобіжником» і модель доходу (розділ 6), щоб AI окупався.
0.3. Обліковий запис розробника Apple — $99 на рік Без Apple Developer Program публікація неможлива. Рекомендую реєструватися як фізособа (Individual): D-U-N-S не потрібен, у магазині продавцем значиться ваше ім'я. Mac не потрібен: збирати застосунок і завантажувати в TestFlight буде GitHub Actions на macOS (для публічного репозиторію безкоштовно).
0.4. Статус «трейдера» за DSA (ЄС) Для продажу в ЄС App Store Connect вимагає вказати, чи ви трейдер. Якщо застосунок платний або з підпискою — так, і тоді в картці застосунку публічно показуються адреса, телефон і e-mail (для фізособи — ваші). Для безкоштовного некомерційного застосунку можна вказати «не трейдер». Варіант з JDG і рахунком для доходів — окреме рішення разом із моделлю доходу.

2. Технічний шлях: PWA → нативний застосунок

Обраний підхід: Capacitor (оболонка iOS) + файли застосунку в самому пакеті Той самий HTML/CSS/JS, що й на сайті, без переписування. Файли застосунку кладемо в пакет, а не вантажимо з сайту: так менше ризику відмови за правилом 4.2 («просто сайт в обгортці»), і застосунок працює офлайн. Великий зміст — книги, аудіо Kokoro (~104 МБ), словники — вантажимо з сайту за потреби, як зараз. Сайт-PWA лишається для Android і комп'ютерів.

Нативні можливості — і для правила 4.2, і для користувачів

  • Віджет на екрані «Додому» (WidgetKit, Swift): стрік, «Мій день», слова на сьогодні — головний аргумент «це не сайт».
  • Локальні нагадування в обраний час без сервера + push від вчителя й друзів (APNs).
  • Нативне розпізнавання мовлення на пристрої (швидше, без ліміту Gemini).
  • Тактильний відгук на правильну/неправильну відповідь, нативний лист «Поділитися», меню на іконці (Quick Actions: «Картки», «Голосовий вчитель»).
  • Офлайн-режим карток, граматики й читання (уже є — показати в описі для перевірки).
  • Пізніше: «Слухати в дорозі» у фоні із заблокованим екраном (нативне аудіо + записи Kokoro) — розв'язує нинішнє обмеження iOS.

Збірка без Mac

  • GitHub Actions macos-latest: npx cap sync ios → xcodebuild archive → завантаження в TestFlight (fastlane + ключ App Store Connect API).
  • Підписування: сертифікат і профіль через fastlane match або автоматичне підписування з API-ключем; секрети — у GitHub Secrets (репозиторій публічний — у код нічого не кладемо).
  • Версія застосунку = BUILD з scripts/bump.sh; окрема команда scripts/ios-release.sh.

5. Бекенд і масштаб

  • Gemini платний тариф: загальний денний/місячний ліміт у _shared/config.ts + запобіжник: бюджет вичерпано → AI для безкоштовних учнів на паузі до завтра, решта застосунку працює. Звіт витрат на #/admin.
  • Ліміт реєстрацій 10 на добу → 200, + захист від ботів (Cloudflare Turnstile у Supabase Auth, безкоштовно).
  • Supabase Free: 500 МБ бази, 1 ГБ файлів, 5 ГБ трафіку на місяць. Голосові чатів і «тоді й зараз» ростуть першими — стиснення, строк зберігання. Перехід на Pro ($25/міс) — орієнтовно від ~300–500 активних учнів або коли потрібні резервні копії.
  • Аудіо й книги на GitHub Pages (ліміти 1 ГБ сайту, ~100 ГБ трафіку на місяць) — зараз ~110 МБ; при зростанні — Cloudflare R2 (безкоштовний вихідний трафік).
  • Моніторинг: журнал помилок і голосові журнали вже є; додати збої нативної оболонки й щоденний звіт «помилки / витрати / нові люди» вам.
  • Функції лише для вас (Resonance, адмінка, «лабораторія») — сховати від усіх інших і з нативної збірки.
