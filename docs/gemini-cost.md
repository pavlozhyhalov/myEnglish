## 1. Умови Google, важливі для нас
| | Безкоштовний ключ | Платний ключ |
|---|---|---|
| Дані учнів | Google **може використовувати** запити й відповіді для покращення своїх продуктів | **Не використовує**; зберігає коротко лише для перевірки зловживань |
| Учні з ЄС / Великої Британії / Швейцарії | Умови Gemini API: **для них дозволено лише платні сервіси** | Дозволено |
| Ліміти | ~20 запитів/день на сильну модель, денні ліміти lite, Live/TTS обмежені | За оплатою, ліміти високі |

**Що це означає зараз.** Учні з Польщі обслуговуються безкоштовним ключем, а це формально суперечить умовам Google для ЄС. До того ж Політика приватності не каже, що Google може вчитися на розмовах.
- Ризик невеликий, поки учнів мало і все безкоштовно. Але **перед App Store потрібен платний ключ**.
- Якщо лишаєтесь на безкоштовному ключі довше — скажіть, і я додам у Політику речення про використання даних Google.

Постійні витрати при запуску:

## 5. Як знизити собівартість (зроблю, коли скажете)
1. **Стиснення контексту Live** (`contextWindowCompression`, ковзне вікно): довга розмова перестає дорожчати з кожною хвилиною. Очікувано −20…40 % ціни голосу.
2. **Ліміти голосу за планом** замість однакових 45 хв/день: зараз один учень може «з'їсти» $20+/міс.
3. **Batch API (−50 %)** для того, що не термінове: нічний глибокий аналіз, підготовка домашнього, озвучення діалогів.
4. Озвучка **Kokoro** для всього постійного змісту — вже зроблено. Gemini TTS лишається лише для відповідей вчителя.
5. Сильні моделі — лише для підсумку й аналізу (уже так, ≤ 8 на день).

3. Підписки в застосунку (StoreKit / In-App Purchase) — окремий етап, коли визначитесь із цінами.
