# Попередня оцінка: чи потрібна DPIA (GDPR ст. 35)

Критерії EDPB (WP248): DPIA обов'язкова, якщо збігаються ≥ 2 ознаки високого ризику. Перелік UODO (Польща) — також.

| Ознака | myEnglish | Збіг |
|---|---|---|
| Оцінювання/скоринг, профілювання | AI оцінює рівень англійської, «пам'ять вчителя» — навчальний профіль; без наслідків для доступу до послуг, роботи, освіти | частково (низький вплив) |
| Автоматизовані рішення з юридичними наслідками | немає | ні |
| Систематичний моніторинг | немає (присутність «у мережі» — лише друзям, вимикається) | ні |
| Чутливі дані (ст. 9) | не збираються навмисно; голос не використовується для ідентифікації (не біометрія за ст. 4(14)); учні можуть самі розповісти про здоров'я — Політика радить не надсилати чутливого | ні (ризик випадкових — пом'якшено) |
| Великий масштаб | десятки учнів | ні |
| Поєднання наборів даних | ні | ні |
| Вразливі особи (діти) | лише з 16 років | ні |
| Нові технології (AI) | так — генеративний AI | так |
| Перешкода у здійсненні прав | ні | ні |

**Висновок (2026-11-28):** одна повна ознака (нові технології) + часткова (навчальний профіль) — **повна DPIA не обов'язкова**. Заходи все одно вжито: окрема згода на AI, мінімізація контексту для AI, видалення текстів розмов через 30 днів, видалення акаунта стирає все, шифровані копії.

**Переглянути оцінку, якщо:** учнів стане тисячі; з'являться користувачі до 16 років або школи як замовники; оцінка рівня почне впливати на доступ (сертифікат, допуск до курсу, роботодавець); голос почне використовуватись для впізнавання людини.
