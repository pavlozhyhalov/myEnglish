- Великі задачі — **через агентів**: поділ за файлами без перетинів, кожен агент комітить свої файли окремо (`git commit -- <файли>`), окремий агент-рецензент; ти — супервайзер (інтегруєш, тестуєш, `scripts/bump.sh`, пуш, деплой, звіт).
- **Доводь задачу до кінця сам.** Якщо агента чи тебе зупинив ліміт (rate limit / usage limit) або перезапуск — **не чекай моїх слів «продовжуй»**:
  одразу після відновлення ліміту продовжуй роботу з місця зупинки (перезапусти/відновлю агентів через `SendMessage`, перевір, що вже закомічено, доробляй решту).
  Якщо ліміт скидається пізніше — **запланувати собі повернення** (`send_later` на час скидання з описом, що доробити) і закінчити роботу без мого втручання. Звітуй лише коли задача закрита повністю (або є справжнє питання до мене).
- Щоб робота не губилась при збоях: агенти комітять часто, проміжні знімки — у гілки `wip/*`; після перезапуску спершу `git log`/`git status`, потім продовження.
- **Якість — найвища:** Playwright-перевірки на iPhone-розмірі (390×844, 320×568, темна й світла тема), живі виклики AI на тестовому акаунті, кілька прогонів. Інтерфейс — літературна українська без русизмів; англійська — британська норма за рівнем.
- Якщо щось блокує (ліміти, підтвердження Supabase) — чесний обхід (SQL без `delete`, `create or replace` замість `drop`), без обходу захисту.
- **Без запитів дозволу мені.** Дані в базі виправляй не прямим `update`/`delete` у `execute_sql` (Supabase просить підтвердження), а через `apply_migration` / функції. Розширити собі дозволи Claude сам не може — я вмикаю режим «Auto» в меню режиму біля поля вводу.

## 3. Технології та інфраструктура
- **Фронтенд:** статична PWA без збірки — HTML + CSS + vanilla JS (ES modules), hash-роутер. Хостинг — **GitHub Pages** з `main` репозиторію `pavlozhyhalov/myEnglish` (публічний). Бібліотеки в `/vendor` (Supabase JS, ts-fsrs). Після кожної зміни фронтенду — `scripts/bump.sh` (версія, кеш SW).
- **Бекенд:** Supabase-проєкт **myEnglish** (`uxqdklwnxdtyifksphoz`, eu-central-1): Postgres з RLS, синхронізація local-first (IndexedDB ↔ Supabase), міграції 0001–0033. Edge-функції (Deno): `tutor` (усі текстові дії AI), `live-token` (голос Gemini Live), `tts`, `pron` (вимова), `push` (нагадування + щоденний автомонітор), `admin`.
- **AI:** Google Gemini, лише безкоштовний ключ (у секретах Supabase). Розподіл моделей у `_shared/config.ts`: важкі оцінки — 3-flash-preview з thinking, чат — 3.5-flash, масові дії — lite; вичерпана модель пропускається до скидання ліміту; щоденний автотест якості виправлень.
- **Деплой функцій:** однорядковий `index.ts` з імпортом `raw.githubusercontent.com/.../<commit-sha>/...` — спершу commit+push, потім деплой з повним SHA.
- **Resonance** (мій інший застосунок): час навчання автоматично йде туди (Мови → English) — лише для мого акаунта.
