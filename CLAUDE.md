# myEnglish — інструкції для Claude Code

Персональна PWA для вивчення англійської. Повне ТЗ — `SPEC.md`. Якщо вимога ТЗ
суперечить твоїй ідеї — спершу перепитай власника (Павло), не змінюй мовчки.
Рішення, ухвалені власником, — у розділі «Рішення» нижче; нова сесія їх не переглядає.

## Стек і правила
- Статика без build-кроку: HTML + CSS + vanilla JS (ES modules). Хостинг — GitHub Pages (`main`, `.nojekyll`).
- Сторонні бібліотеки лише вендорені в `/vendor` (`supabase.js`, `ts-fsrs.js` — ESM-збірки esbuild). Без CDN у рантаймі.
- Бекенд — окремий Supabase-проєкт **myEnglish** (`uxqdklwnxdtyifksphoz`, eu-central-1). Не Resonance.
- Gemini API key — лише в секретах Supabase (`GEMINI_API_KEY`). Перед комітом: `git grep -nE "AIza|sk-|service_role"` має бути порожнім.
- Усі рядки інтерфейсу — українською; спільні — у `js/strings.js`.
- AI-відповіді в DOM — лише через `textContent` або `js/ui/md.js` (без innerHTML сирого тексту). md.js: вкладені `*курсив **жирний***`, `~~закреслене~~`; формули — `mdInline()`.
- **Будь-яка зміна фронтенду → `scripts/bump.sh`** (піднімає BUILD у `js/config.js`, `sw.js`, `?v=` в `index.html`, пише `precache-list.js` з хешами вмісту — SW копіює незмінені файли зі старого кешу; перераховує `count`/`withEx` у `data/decks/index.json`).

## Як працювати
- Автономно до повного закриття задачі; звіт власнику — українською, коли все зроблено й перевірено.
- **Ліміти й перезапуски — не привід чекати власника** (рішення власника 2026-11-08): якщо агента чи сесію зупинив rate/usage limit або перезапуск —
  щойно ліміт відкрився, продовжувати самостійно (відновити агентів через `SendMessage`, перевірити `git log`/`git status`, доробити решту), не чекаючи «продовжуй».
  Якщо ліміт скидається пізніше — запланувати собі повернення (`send_later` на час скидання з описом незробленого). Агенти комітять часто (по файлу/сторінці), проміжні знімки — у `wip/*`.
- `CONTEXT.md` — опис проєкту для нового діалогу; оновлювати після великих змін.

## Структура
- `js/app.js` — старт, шапка, маршрути, синхронізація, SW. `js/router.js` — hash-роутер: кожна сторінка рендериться у власний контейнер (`[data-page]`),
  прибирання — функція, яку повертає сторінка, або `onLeave(view, fn)` для довгих async-сценаріїв (голос, тести).
- `js/store.js` — локальний стан (IndexedDB) + синхронізація з Supabase: черга `dirty`, upsert з `defaultToNull: false`, pull за серверним `synced_at` (міграція 0008),
  на сервері тригер `sync_guard` — старіший `updated_at` не перезаписує новіший. Видалення всюди м'яке (`deleted`). Збій однієї таблиці не блокує решту.
- `js/srs.js` — FSRS (ts-fsrs) і черга карток. Стартові картки з `data/decks/*.json` потрапляють у БД лише після першого показу (id = `deck:slug(en)`).
- `js/stats.js` — сесії (час), стрік, помилки, прогрес уроків.
- `js/ai.js` — виклики edge-функцій; `js/speech.js` — TTS/розпізнавання; `js/live/*` — Gemini Live (WebSocket + AudioWorklet) і режим «рація».
- `js/ui/*` — компоненти (drawer, quickbar, sheet, toast, exercises, md, icons). `js/pages/*` — по файлу на розділ.
- `supabase/migrations/*` — SQL; `supabase/functions/{tutor,live-token,tts,_shared}` — edge-функції (Deno).
- Контент (усе з полем `level` A1–C1): `data/decks` (48 колод, ~2275 карток, ~400 на рівень), `data/grammar` (84 уроки), `data/scenarios.json`, `writing.json`, `listening.json`, `pronunciation.json`, `placement.json`.

## Деплой
- Фронтенд: push у `main` → GitHub Pages.
- Edge-функції: деплой через Supabase MCP (`deploy_edge_function`, `verify_jwt: false` — функції самі перевіряють JWT і allowlist).
  Точка входу — однорядковий `index.ts`, що імпортує `https://raw.githubusercontent.com/pavlozhyhalov/myEnglish/<commit-sha>/supabase/functions/<fn>/index.ts`.
  Порядок: зміни → commit → push → передеплой з новим SHA (закріплення на коміті, не на `main`). Репозиторій має бути публічним; якщо стане приватним — деплоїти файли напряму.
- Міграції: `apply_migration`, файли зберігати в `supabase/migrations`.
- Секрети функцій: `GEMINI_API_KEY` (обов'язково), `ALLOWED_USERS` (адміністратори: uuid або email через кому), опційно `ACCESS_MODE=allowlist`, опційно `GEMINI_TEXT_MODEL`, `GEMINI_TTS_MODEL`, `GEMINI_LIVE_MODEL`, `LIMIT_*`.
