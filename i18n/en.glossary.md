# Glossary en: English interface (2026-11-26)

For translators of the interface (`i18n/en*.json`) and content (`data/l10n/en/*`). The app teaches English; the English interface is for learners whose own language is not among the app's languages, and for App Store review. British spelling and usage (colour, practise (verb), programme, learnt/learned both fine, “mobile”, “flat”), plain and friendly like Duolingo or Apple. Second person “you”.

## Special rules for English (read carefully)
- The learner reads the interface in English, so write **simple English (B1 level)**: short sentences, common words, no idioms in instructions.
- **Card meanings / glossaries / word translations** (Ukrainian translation of an English word): write a short English gloss or synonym that explains the meaning, e.g. «наполегливий» for *persistent* → “determined, not giving up”. Never just repeat the English word itself.
- **Ukrainian translations of English example sentences** (field shown under an English example): write a plain English paraphrase, or simply repeat the English sentence if a paraphrase is pointless.
- **Exercise prompts that ask to translate from Ukrainian into English**: translate the Ukrainian sentence into English but **paraphrase** it (different words, same meaning), so the exercise becomes “say it in another way”, never a copy of the answer.
- Mentions of “Ukrainian” as the learner's language (“українською”, “для українців”, “з української”) → “in your language” / “for learners” / omit. “Ukrainian” as a language name in the language list stays “Ukrainian”.
- Typical mistakes “of Ukrainians” → “typical learner mistake” (keep the explanation).
- Do not adapt Ukrainian cultural examples (Kyiv, borscht, Oksana): keep them as they are.
- Keep English examples, level names (A1, B2, Pre-A1), «myEnglish», tense names (Present Perfect), Markdown (`**bold**`, `*italic*`, `\n`), symbols (✓ · → ×) unchanged. Quotes: use “…”.
