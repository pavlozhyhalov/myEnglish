# Інструкція: «Коли й навіщо» для уроків граматики (поле `guide`)

Власник (2026-11-23): «Все якось зливається в описанні, тяжко для сприйняття. Треба нормальна інформація, для чого і коли вживається
(це стосується всього в граматиці). Наприклад, Perfect описується лише як вживати, а коли і для чого — незрозуміло. Хочу люксовий продукт».

Учні — українці, які вчать загальну англійську для спілкування (рівні A0 «Pre-A1» … C1). Пишемо як найкращий вчитель:
коротко, по-людськи, конкретно, з прикладами з життя. Не підручник і не вікіпедія.

## Зразки (прочитати першими)
`data/grammar/present-perfect.json` і `data/grammar/prepositions-time.json` — поля `guide` і `explanation`. Це еталон обсягу, тону й структури.
Як це виглядає: сторінка уроку `#/grammar/<id>` рендерить `guide` у `js/pages/grammar.js` (`guideGroups`, `guideTail`).

## Що робити з кожним файлом своєї групи
1. **Аналіз.** Прочитай увесь урок (title, titleEn, explanation, formula, table, examples, tip, exercises).
   Визнач: що учень мусить зрозуміти — НАВІЩО ця конструкція, КОЛИ її обирати замість інших, з чим українці її плутають і які помилки роблять.
   Перевір, чи не бракує важливих випадків уживання для цього рівня (порівняй з Cambridge English Grammar in Use / English Profile).
2. **Напиши `guide`** (вставити одразу після `explanation`; інші поля не переставляти):
   - `idea` — 1–2 речення: суть і навіщо. Простими словами, без зайвих термінів. Не формула.
   - `use` — 2–6 випадків «коли вживати»: `{ "when", "note", "en", "uk" }`.
     `when` — коротка назва випадку (2–6 слів), `note` — одне речення: як упізнати / чому саме так, `en` — природний приклад з життя, `uk` — природний переклад.
   - `vs` — 0–3 порівняння з тим, з чим плутають: `{ "title": "X чи Y?", "a": { "en", "uk", "note" }, "b": { "en", "uk", "note" } }`. `note` пояснює різницю в сенсі.
     Порожній масив, якщо плутати нема з чим.
   - `signals` — слова-підказки (англ., 0–12), лише якщо вони справді є (ever, yet, since…). Інакше `[]`.
   - `mistakes` — 2–5 типових помилок українців: `{ "wrong", "right", "why" }` — кальки з української, пропущені/зайві слова, плутанина часів. `why` — одне речення.
3. **Перепиши `explanation`** лише як «Як утворити»: форма (+ / − / ?), правопис, порядок слів, винятки — коротко, рядками й списками
   (одиночний перенос рядка = новий рядок; порожній рядок = новий абзац). Не повторюй те, що вже є в `guide` і `formula`. Якщо форма тривіальна (прийменники, артиклі) — короткий конспект-шпаргалка.
4. `title`, `titleEn`, `unit`, `level`, `mistakeType`, `formula`, `table`, `examples`, `tip`, `exercises`, `id` — **не змінювати** (від них залежать прогрес і вправи).
   Виняток: явна фактична помилка в `formula`/`table`/`tip` — виправ і напиши про це у звіті.

## Правила мови й змісту
- Українська — літературна, без русизмів і кальок («вживати», а не «використовувати» всюди; «наприклад», «зверніть увагу» — не «обратите»). Звертання — безособово або на «ви».
- Англійська — **британська норма** (at the weekend, have got, flat, holiday, colour), природна розмовна, рівень уроку (A0–A1 — дуже прості слова; C1 — можна багатше).
- Приклади — з життя: робота, родина, магазин, подорожі, друзі. **Український колорит вітається** (рішення власника 2026-11-24): приблизно кожен 3–4-й приклад може бути з України — Київ, Львів, Одеса, Харків, Дніпро, Карпати, Дніпро-ріка, борщ, вареники, сало, Різдво з кутею, українські імена (Oksana, Taras, Olena, Andrii, Iryna, Mykola — у перекладі Оксана, Тарас…), решта — британські реалії (London, Leeds, Edinburgh, Oliver, Emma). Колорит без політики й війни. **Жодних особистих даних власника**: не Краків і не Польща як місце, де «я живу», не «моя дружина», не професія чи сім'я власника.
- Для **A0** (Pre-A1): `idea` — 1 коротке речення; `use` — 2–3 випадки; `vs` — 0–1; `mistakes` — 2–3; слова лише з найпростіших (I'm, my name, this, cat, apple…).
- Розмітка в рядках: `**жирний**`, `*курсив*`. Без HTML, без емодзі, без LaTeX. У `when` — без крапки в кінці.
- Без «води»: жодних «Це дуже важлива тема», «Давайте розберемо». Кожне речення має допомагати вирішити, яку форму обрати.
- Факти мають бути правильними (перевір кожен приклад: граматика, природність, британський варіант).

## Як працювати
- JSON писати скриптом Python (`json.load` → зміни → `json.dump(..., ensure_ascii=False, indent=2)` + `\n` в кінці), щоб не зламати файл. Після кожного файлу — `python3 -c "import json;json.load(open(F))"`.
- **Не комітити й не пушити** (кілька агентів працюють в одній робочій теці; git робить супервайзер). Змінювати лише файли своєї групи; `scripts/bump.sh` не запускати.
- Перевірка схеми свого файлу: `node scripts/check-guide.js data/grammar/<id>.json`.
- Якщо роботу перервано (ліміт) — продовжуй з першого файлу групи без `guide`.
- У кінці — звіт супервайзеру: які файли зроблено, що виправлено поза `guide`, сумнівні місця.

## Рецензія (агент-рецензент)
Рецензент перевіряє кожен урок своєї групи як вимогливий методист і редактор і **сам виправляє** знайдене (не лише звітує):
1. **Правильність англійської**: кожне речення в `guide` і `explanation` граматично правильне, природне, британська норма, лексика рівня уроку. Правила сформульовані точно (без хибних «завжди/ніколи»).
2. **Повнота «коли й навіщо»**: чи зрозуміло з `idea` + `use`, навіщо конструкція і як обрати її замість альтернативи; чи є головне порівняння `vs`, з яким реально плутають; чи відповідають `mistakes` справжнім помилкам українців. Бракує — допиши; зайве чи вище рівня — прибери.
3. **Читабельність**: короткі речення, без води й повторів між `guide`, `explanation`, `formula`, `tip`; `when` — 2–6 слів; `note` — одне речення.
4. **Українська**: літературна, без русизмів і кальок, однакова термінологія (Present Perfect, дієслово, підмет), «ви»/безособово.
5. **Узгодженість з уроком**: `guide` не суперечить `formula`, `table`, `tip`, `examples`, `exercises`.
6. **Особисті дані власника — прибрати з УСЬОГО файлу** (і з `examples`, `table`, `tip`, `exercises`): Kraków/Krakow, Wawel, Vistula, Planty, Kazimierz, Nowa Huta; «моя дружина / my wife», переїзд до Польщі («moved to Poland»), злоті, карта побиту, CNC/фрезерування/виробництво як особистий досвід. Заміни нейтральними британськими реаліями (London, Leeds, Edinburgh, Manchester, pounds), зберігаючи граматику вправи.
   У `exercises` змінюй лише слова-реалії в `sentence`/`prompt`/`uk`/`answer`/`options`/`alt`/`explanation` так, щоб правильна відповідь лишилась правильною й однаковою скрізь (структуру, `type`, кількість варіантів, індекс `answer` не міняти). Загальні згадки Польщі як країни без прив'язки до «я/ми живемо» можна лишити.
7. Після правок: `node scripts/check-guide.js data/grammar/<id>.json` і `python3 -c "import json;json.load(open(F))"`. Не комітити.
Звіт: по кожному файлу — що виправлено (коротко), окремо — що вирішити власнику.
