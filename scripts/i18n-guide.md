# Інструкція перекладача (myEnglish, мови інтерфейсу й змісту)

Застосунок вчить **англійської** людей з різних країн. База — українська; ти перекладаєш українські рядки на мову учня.
Механізм — `js/i18n.js`: словник «точний український рядок → переклад». Ключ НЕ змінювати (навіть пробіли й розділові знаки).

## Файли
- Інтерфейс: ключі `i18n/_keys.json` → пишеш `i18n/<lang>.json` — об'єкт `{ "укр. рядок": "переклад", … }`.
- Шаблони з числами/змінними: `i18n/_patterns.json` (`{ re, src }`) → пишеш `i18n/<lang>.patterns.json` — масив `[[re, заміна], …]`, де `re` — **точно** поле `re` з `_patterns.json`.
  У заміні: `$1`, `$2`… — групи `(.+?)` по порядку; група `(?:день|дні|днів)` НЕ нумерується. Число з правильною формою слова — `{$1|one|few|many|other}`
  (форми за CLDR твоєї мови: es/pt — `{$1|día|días}`, tr — `{$1|gün}`, pl/ru — `{$1|dzień|dni|dni}` / `{$1|день|дня|дней}`; число підставиться саме перед словом).
  Приклад: re `^Стрік: (\\d+) (?:день|дні|днів) поспіль$` → es `Racha: {$1|día|días} seguidos`.
  Якщо група — не число (назва, слово), просто `$1`. Шаблон, який неможливо перекласти розумно (склеєні слова, відмінки змінної) — пропусти.
- Зміст: ключі `data/l10n/_keys/<шлях>.json` → пишеш `data/l10n/<lang>/<шлях>.json` — той самий словник `{ "укр.": "переклад" }` для кожного рядка.

**ru — для російськомовних українців і всіх, крім Росії** (рішення власника): жодних згадок про Росію, російські міста, культуру чи реалії; «в Украине» (НЕ «на Украине»); українські назви — як в українських російськомовних медіа: Киев, Львов, Одесса, Харьков, Днепр, Карпаты; українські страви й свята лишаються українськими (борщ, вареники, кутья). Тон — теплий, як у української версії.

## Адаптація під регіон (рішення власника 2026-11-24: «вчитель і вправи адаптуються під регіон мови; російська — під Україну»)
Регіон мови: es — Іспанія й Латинська Америка (Madrid, Mexico City, Buenos Aires, Bogotá; paella, tacos, empanadas; імена Lucía, Mateo, Sofía, Diego), pt — Бразилія (São Paulo, Rio de Janeiro, Salvador; feijoada, pão de queijo; Ana, João, Beatriz, Pedro), tr — Туреччина (İstanbul, Ankara, İzmir; kebap, baklava, çay; Elif, Mehmet, Zeynep, Emre), pl — Польща (Warszawa, Gdańsk, Wrocław; pierogi, żurek; Kasia, Tomek, Ania, Piotr), ru — **Україна** (українські реалії лишаються як є).
- У перекладах змісту українські реалії (Київ, Львів, борщ, вареники, Оксана, Тарас, гривні…) заміни реаліями регіону — і в українському тексті-перекладі, і в **англійських прикладах**: словник змісту приймає й англійські ключі — точний англійський рядок → адаптований англійський рядок (наприклад, `"We eat varenyky on Christmas Eve."` → pl `"We eat pierogi on Christmas Eve."`). Британські реалії (London, Emma, pounds) лишаються — їх половина.
- **Не адаптуй** англійський текст, який озвучено записом або від якого залежить прогрес: поле `en` карток колод, репліки діалогів і диктант (`data/listening.json`), фрази вимови (`data/pronunciation.json`), абзаци читання (`data/reading.json`), відповіді тесту рівня. Там перекладай лише український текст.
- У вправах адаптуй узгоджено: речення, варіанти, правильна відповідь, пояснення — одна й та сама реалія; структура й індекси без змін. Якщо адаптація ламає граматику вправи (артикль, однина/множина) — не адаптуй.
- Без політики, війни, релігійних суперечок; для ru — жодної Росії. Для pl — **не Kraków** (особисті дані власника): Warszawa, Gdańsk, Wrocław, Poznań, Łódź.

## Правила
- Переклад **природний**, як у найкращих застосунках (Duolingo, Apple), а не дослівний. Короткі назви кнопок і плиток — короткі (плитки вузькі, 3 в ряд на телефоні).
- Англійські слова, приклади, назви рівнів (A1, B2, Pre-A1), «myEnglish», назви ігор англійською — **не перекладати**. Розмітку `**жирний**`, `*курсив*`, `\n`, `«…»` (лапки можна замінити на звичні для мови), емодзі-символи (✓ · → ×) — зберігати.
- Терміни граматики — як у підручниках англійської для носіїв твоєї мови (Present Perfect лишається англійською назвою).
- Згадки «українською», «українців», «з української» в інтерфейсі: про **мову учня** → «твоєю/вашою мовою», «рідною мовою»; рядки про українську як мову застосунку (наприклад, назва мови в списку) — перекладай буквально.
- Типові помилки «українців» (кальки з української) у змісті: перекладай пояснення нейтрально («типова помилка», без «з української»), якщо помилка не має сенсу для носія твоєї мови — однаково перекладай (окремі помилки для кожної мови будуть пізніше).
- Нічого не вигадуй і не прибирай: один рядок — один переклад. Порожніх значень не лишай.
- Глосарій мови — `i18n/<lang>.glossary.md` (створює перекладач інтерфейсу: ~60 ключових термінів — назви розділів, кнопок, «картки», «Мій день», «стрік», «вчитель» тощо). Перекладачі змісту читають його й дотримуються.

## Як працювати
- Пиши JSON скриптом Python (`json.dump(..., ensure_ascii=False, indent=1)` + `\n`), великими порціями (по 300–500 рядків), після кожної порції — `json.load` і `node scripts/check-i18n.js <lang>`.
- Скрипти тримай у власній теці в scratchpad (інші агенти працюють паралельно). **Не комітити й не пушити** — git робить супервайзер.
- Перервали (ліміт) — продовжуй з того, чого ще немає у файлі (`node scripts/check-i18n.js <lang> --list`).
